## English

API Isarud is the most comprehensive free multi-marketplace integration plugin for WooCommerce. It connects Trendyol, Etsy, Hepsiburada, N11, Amazon SP-API, Pazarama and eBay to a single WordPress panel.

**Marketplaces (7):** Trendyol, Etsy, Hepsiburada, N11, Amazon SP-API, Pazarama, eBay

**Key features:** Sanctions screening, two-way stock and price sync, automatic product export, order management, returns and invoices, customer questions - all 100% free.

- Sanctions Screening: Screen customers and companies against 32,500+ sanctioned entities from 8 global lists (OFAC SDN, OFAC Consolidated, EU, UN, UK HMT, Canada SEMA, Australia DFAT, World Bank). Fuzzy matching with configurable threshold, automatic screening on new orders, optional order blocking, alert emails, and a full audit trail.
- Auto-Export: When you add or update a product in WooCommerce, it is automatically sent to all connected marketplaces with no manual work. Enable per product and per marketplace with a single toggle.
- Order Management: Automatic order status sync (Picking, Shipped, Cancelled, Delivered), cargo assignment via marketplace APIs, order import from all marketplaces, and scheduled automatic import.
- Returns and Refunds: Fetch return and claim requests from marketplaces, then approve or reject them directly from the WordPress admin.
- Invoice Management: Send invoice links to marketplaces, automatically on order completion or manually from the admin.
- Customer Questions: Fetch buyer questions and reply directly from the WordPress admin, with automatic notifications for new questions.
- eBay Integration (new in v6.7): OAuth managed via the isarud.com cloud bridge, with a 4-tab admin page (Products, Orders, Finances, Analytics).
- Cloud Sync: Sync your WooCommerce data to your isarud.com account, with iOS, Android, and desktop companion apps for centralized multi-store management.
- 16 Languages: Fully translated storefront and admin interface, with marketplace-specific terminology localized.

### Installation

1. In WordPress admin, go to Plugins, Add New, search for Isarud or api-isarud, then click Install Now and Activate.
2. Alternatively, download from WordPress.org or GitHub, upload the api-isarud folder to /wp-content/plugins/, and activate it from the Plugins menu.

### Configuration

1. Go to Isarud, Marketplace API and click the connect button on any marketplace card.
2. Sign in or create an account at isarud.com, select your marketplace store, and authorize the connection.
3. Go to Isarud, Cloud Sync to enter your API key and enable automatic sync for orders, stock, and returns.

### 설치

1. WordPress 관리자에서 플러그인, 새로 추가로 이동하여 Isarud 또는 api-isarud를 검색한 후 지금 설치 및 활성화를 클릭합니다.
2. 또는 WordPress.org 또는 GitHub에서 다운로드하여 api-isarud 폴더를 /wp-content/plugins/에 업로드하고 플러그인 메뉴에서 활성화합니다.

### 설정

1. Isarud, Marketplace API로 이동하여 마켓플레이스 카드의 연결 버튼을 클릭합니다.
2. isarud.com에서 로그인하거나 계정을 만들고, 마켓플레이스 스토어를 선택한 후 연결을 승인합니다.
3. Isarud, Cloud Sync로 이동하여 API 키를 입력하고 주문, 재고 및 반품에 대한 자동 동기화를 활성화합니다.

## हिन्दी

API Isarud WooCommerce के लिए सबसे व्यापक मुक्त बहु-बाजार एकीकरण प्लगइन है। यह Trendyol, Etsy, Hepsiburada, N11, Amazon SP-API, Pazarama और eBay को एक एकल WordPress पैनल से जोड़ता है।

**बाजार (7):** Trendyol, Etsy, Hepsiburada, N11, Amazon SP-API, Pazarama, eBay

**मुख्य विशेषताएं:** प्रतिबंध जांच, दोतरफा स्टॉक और मूल्य समन्वय, स्वचालित उत्पाद निर्यात, ऑर्डर प्रबंधन, रिटर्न और चालान, ग्राहक प्रश्न - सभी 100% मुक्त।

- प्रतिबंध जांच: ग्राहकों और कंपनियों की 8 वैश्विक सूचियों (OFAC SDN, OFAC Consolidated, EU, UN, UK HMT, Canada SEMA, Australia DFAT, World Bank) से 32,500+ प्रतिबंधित संस्थाओं के विरुद्ध जांच करें। कॉन्फ़िगर करने योग्य थ्रेसहोल्ड के साथ फज़ी मिलान, नए ऑर्डर पर स्वचालित जांच, वैकल्पिक ऑर्डर ब्लॉकिंग, अलर्ट ईमेल और पूर्ण ऑडिट ट्रेल।
- स्वचालित निर्यात: जब आप WooCommerce में एक उत्पाद जोड़ते या अपडेट करते हैं, तो इसे स्वचालित रूप से सभी जुड़े बाजारों को भेजा जाता है बिना किसी मैनुअल काम के। एक एकल टॉगल से प्रति उत्पाद और प्रति बाजार सक्षम करें।
- ऑर्डर प्रबंधन: स्वचालित ऑर्डर स्थिति समन्वय (पिकिंग, शिप किया गया, रद्द किया गया, डिलीवर किया गया), बाजार API के माध्यम से कार्गो असाइनमेंट, सभी बाजारों से ऑर्डर आयात, और निर्धारित स्वचालित आयात।
- रिटर्न और धनवापसी: बाजारों से रिटर्न और दावा अनुरोध प्राप्त करें, फिर WordPress व्यवस्थापक से सीधे उन्हें स्वीकृत या अस्वीकार करें।
- चालान प्रबंधन: बाजारों को चालान लिंक भेजें, ऑर्डर पूरा होने पर स्वचालित रूप से या व्यवस्थापक से मैनुअली।
- ग्राहक प्रश्न: खरीदार प्रश्न प्राप्त करें और WordPress व्यवस्थापक से सीधे उत्तर दें, नए प्रश्नों के लिए स्वचालित सूचनाओं के साथ।
- eBay एकीकरण (v6.7 में नया): isarud.com क्लाउड ब्रिज के माध्यम से प्रबंधित OAuth, 4-टैब व्यवस्थापक पृष्ठ (उत्पाद, ऑर्डर, वित्त, विश्लेषण) के साथ।
- Cloud Sync: अपने WooCommerce डेटा को अपने isarud.com खाते में सिंक करें, iOS, Android, और डेस्कटॉप साथी ऐप्स के साथ केंद्रीकृत बहु-स्टोर प्रबंधन के लिए।
- 16 भाषाएं: पूरी तरह से अनुवादित स्टोरफ्रंट और व्यवस्थापक इंटरफेस, बाजार-विशिष्ट शब्दावली स्थानीयकृत के साथ।

### स्थापना

1. WordPress व्यवस्थापक में, प्लगइन पर जाएं, नया जोड़ें, Isarud या api-isarud खोजें, फिर अभी स्थापित करें और सक्रिय करें पर क्लिक करें।
2. वैकल्पिक रूप से, WordPress.org या GitHub से डाउनलोड करें, api-isarud फ़ोल्डर को /wp-content/plugins/ में अपलोड करें, और प्लगइन मेनू से सक्रिय करें।

### कॉन्फ़िगरेशन

1. Isarud पर जाएं, बाजार API और किसी भी बाजार कार्ड पर कनेक्ट बटन पर क्लिक करें।
2. isarud.com पर साइन इन करें या खाता बनाएं, अपना बाजार स्टोर चुनें, और कनेक्शन को अधिकृत करें।
3. Isarud पर जाएं, Cloud Sync अपनी API कुंजी दर्ज करने और ऑर्डर, स्टॉक और रिटर्न के लिए स्वचालित समन्वय सक्षम करने के लिए।

## Bahasa Indonesia

API Isarud adalah plugin integrasi multi-marketplace gratis paling komprehensif untuk WooCommerce. Ini menghubungkan Trendyol, Etsy, Hepsiburada, N11, Amazon SP-API, Pazarama, dan eBay ke satu panel WordPress.

**Marketplace (7):** Trendyol, Etsy, Hepsiburada, N11, Amazon SP-API, Pazarama, eBay

**Fitur utama:** Pemeriksaan sanksi, sinkronisasi stok dan harga dua arah, ekspor produk otomatis, manajemen pesanan, pengembalian dan faktur, pertanyaan pelanggan - semuanya 100% gratis.

- Pemeriksaan Sanksi: Periksa pelanggan dan perusahaan terhadap 32.500+ entitas tersanksi dari 8 daftar global (OFAC SDN, OFAC Consolidated, EU, UN, UK HMT, Canada SEMA, Australia DFAT, World Bank). Pencocokan fuzzy dengan ambang batas yang dapat dikonfigurasi, pemeriksaan otomatis pada pesanan baru, pemblokiran pesanan opsional, email peringatan, dan jejak audit lengkap.
- Ekspor Otomatis: Ketika Anda menambah atau memperbarui produk di WooCommerce, produk tersebut secara otomatis dikirim ke semua marketplace yang terhubung tanpa pekerjaan manual. Aktifkan per produk dan per marketplace dengan satu pengalihan.
- Manajemen Pesanan: Sinkronisasi status pesanan otomatis (Pengambilan, Dikirim, Dibatalkan, Terkirim), penugasan kargo melalui API marketplace, impor pesanan dari semua marketplace, dan impor otomatis terjadwal.
- Pengembalian dan Pengembalian Dana: Ambil permintaan pengembalian dan klaim dari marketplace, kemudian setujui atau tolak langsung dari admin WordPress.
- Manajemen Faktur: Kirim tautan faktur ke marketplace, secara otomatis setelah penyelesaian pesanan atau secara manual dari admin.
- Pertanyaan Pelanggan: Ambil pertanyaan pembeli dan balas langsung dari admin WordPress, dengan notifikasi otomatis untuk pertanyaan baru.
- Integrasi eBay (baru di v6.7): OAuth dikelola melalui jembatan cloud isarud.com, dengan halaman admin 4 tab (Produk, Pesanan, Keuangan, Analytics).
- Cloud Sync: Sinkronkan data WooCommerce Anda ke akun isarud.com Anda, dengan aplikasi pendamping iOS, Android, dan desktop untuk manajemen multi-toko terpusat.
- 16 Bahasa: Antarmuka storefront dan admin yang sepenuhnya diterjemahkan, dengan terminologi khusus marketplace yang dilokalisasi.

### Instalasi

1. Di admin WordPress, buka Plugin, Tambah Baru, cari Isarud atau api-isarud, kemudian klik Instal Sekarang dan Aktifkan.
2. Sebagai alternatif, unduh dari WordPress.org atau GitHub, unggah folder api-isarud ke /wp-content/plugins/, dan aktifkan dari menu Plugin.

### Konfigurasi

1. Buka Isarud, Marketplace API dan klik tombol sambungkan pada kartu marketplace apa pun.
2. Masuk atau buat akun di isarud.com, pilih toko marketplace Anda, dan otorisasi koneksi.
3. Buka Isarud, Cloud Sync untuk memasukkan kunci API Anda dan aktifkan sinkronisasi otomatis untuk pesanan, stok, dan pengembalian.
